Cara pakai:
1. Extract ZIP ini.
2. Double click index.html untuk preview.
3. Edit nama, tanggal, alamat, dan link WhatsApp langsung di index.html.
4. Edit countdown di js/script.js pada baris invitationDate.
5. Semua asset gambar ada di folder assets.
6. Kalau upload ke hosting/Vercel/Netlify, upload seluruh folder ini.

Catatan:
- Ini versi HTML statis, tidak butuh npm, tidak butuh build.
- Placeholder Gallery bisa diganti pakai foto kamu sendiri.
